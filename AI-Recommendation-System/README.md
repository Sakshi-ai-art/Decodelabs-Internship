# AI Career Recommendation System

This repository hosts the **AI Career Recommendation System**, built as part of the **DecodeLabs Internship**. 

It is a Streamlit-based web application designed to recommend career paths to users by matching their technical skill sets with standard industry requirements, displaying a compatibility score, and listing missing skills to help them guide their learning path.

---

## 🚀 Features

- **Interactive Skill Selector**: Users can choose multiple skills from a predefined list (Python, SQL, Machine Learning, etc.).
- **Smart Matching Algorithm**: Calculates a compatibility percentage based on matching skills against various career paths.
- **Actionable Gap Analysis**: Computes and displays specific missing skills for each recommendation to help users bridge technical gaps.
- **Modern User Interface**: A clean, reactive Streamlit dashboard.

---

## 🛠️ Tech Stack

- **Frontend/Backend**: [Streamlit](https://streamlit.io/)
- **Data Manipulation**: [Pandas](https://pandas.pydata.org/)
- **Programming Language**: Python 3

---

## 📦 Installation & Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Sakshi-ai-art/Decodelabs-Internship.git
   cd Decodelabs-Internship/AI-Recommendation-System
   ```

2. **Install Dependencies**:
   Ensure you have Python installed, then run:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Streamlit App**:
   ```bash
   streamlit run app.py
   ```
